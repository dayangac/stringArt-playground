String Art

Winds a photograph as one continuous thread between pins on a circular frame. Greedy chord selection — the unoptimised baseline: it never reconsiders a chord it has placed, and it does not yet account for how much thread each one costs. Thread is opaque, so colours mix optically rather than like ink: the palette is clustered out of your image in OKLab, and each crossing pulls the board a fraction of the way towards that thread's colour. Matching the board to the image is the cheapest saving there is — thread only has to cover what differs from it. Thread economy then ranks chords by what they buy per metre and drops the ones that stop paying, at the cost of a few cuts.
